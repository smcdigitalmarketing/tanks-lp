# Asset manifest

Generated by `npm run assets:manifest` from `app/data/catalog.json` and `app/data/reviews.json` (ported 2026-11-09 from https://maggies-tanks.com/products/maggies-built-in-comfort-bra-tanktop). Don't edit by hand.

**Nothing in this list is cleared for production.** Every file comes from the competitor's public store and is used here only for internal concept evaluation. All three concepts use the same files in the same slots, so the comparison is about branding, not photography.

- 33 assets recorded: 25 in use, 8 recorded but not used.
- Photos are saved at native size as webp (`app/assets/store/`), never upscaled on disk. The 1600 × 1600 gallery exports in `public/gallery/` are rendered by `npm run gallery:export` and contain no competitor text.
- Product images were fetched from the public product JSON (`/products/<handle>.json`); page images and the video from public CDN URLs in the page HTML; review photos from Judge.me's public review widget. No protected endpoints.

## Flags

| Flag | Meaning |
|---|---|
| `rights` | Competitor's asset. Usage rights not cleared: approval or replacement needed before production. |
| `ai-likely` | Filename suggests AI generation (freepik, magnific, nano banana, ChatGPT). Check provenance. |
| `low-res` | Below 1600 px. Gallery exports at 1600 px are upscaled and slightly soft. |
| `not-square` | Not square; cropped to fit square slots. |
| `before-after` | Before/after style image. Implies a body-shape result; only used (if at all) with construction-only labels. |
| `cross-store` | Served from a different Shopify store (files/1/0962/4692/3588), origin unclear. |
| `text-baked-in` | Words are part of the image; not usable in the gallery (all text must be HTML). |
| `conflicting` | Its content contradicts other source pages. |
| `real-person` | A real customer's photo from a public review. Needs consent before any production use. |
| `unverified-person` | Shows a person the source presents as its founder; identity unverified. |
